05 — GETTING STARTED

几步开始
你的经典之旅。

正式版本发布后，请以压缩包内说明为准。以下为通用准备流程。

STEP 01准备启动器

准备支持旧版 Minecraft 的启动器，例如 PCL2，并确认启动器能够正常运行。

STEP 02检查 Java 环境

根据整合包实际启动要求配置 Java。不要仅凭版本号猜测运行环境。

STEP 03导入整合包

使用发布说明指定的导入方式安装整合包，并确认游戏目录位置。

STEP 04启动并反馈

首次启动后检查日志。如遇到问题，请附上完整错误日志与模组列表。

06 — FAQ

常见问题

这是哪个 Minecraft 版本？+

项目定位为 Minecraft Java Edition 1.6.4 Forge 整合包。实际 Forge 构建号与启动要求请以发行说明为准。

现在可以直接下载整合包吗？+

请查看 GitHub Releases。如果没有正式发行文件，说明版本仍在准备中；请不要下载来源不明的同名文件。

遇到崩溃或模组冲突怎么办？+

请保留完整的 latest.log、崩溃报告、启动器版本和复现步骤，然后通过 GitHub Issues 反馈。

如何查看项目最新进展？+

关注项目 GitHub 仓库的提交记录、Releases 和 Issues。
